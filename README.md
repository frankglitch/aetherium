# Aetherium

## Shader packs on Minecraft's Vulkan renderer

- make "aeth" folder under name home.

Required dependencies
Sodium — Version 0.9.2 or newer for Minecraft 26.3.
Fabric API — Required when running Aetherium on Fabric.
Required mod loader
Fabric Loader — Version 0.19.5 or newer.
NeoForge — Version 26.3.0.23-beta or newer.
